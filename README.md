# 🌤️ Weather App

A lightweight and easy-to-use Android application built with Kotlin that provides real-time weather details for any city worldwide.

---

## ✨ Features

* **City Search:** Easily search weather details by typing any city name.
* **Current Temperature:** Displays live temperature in Celsius (°C).
* **Humidity Levels:** Shows real-time relative humidity percentage.
* **Weather Conditions:** View real-time atmospheric conditions (e.g., Clear, Rain, Clouds).

---

## 🛠️ Built With

* **Language:** [Kotlin](https://kotlinlang.org/)
* **UI Tooling:** Android SDK / Material Design
* **Networking:** API Integration (e.g., OpenWeatherMap API)
